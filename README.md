# Bank Fraud Detection on Payment Transactions

## Project Overview
This project focuses on detecting fraudulent bank/payment transactions using data analysis and machine learning techniques.

## Objectives
- Analyze transaction data to identify fraud patterns
- Clean and preprocess data
- Handle class imbalance
- Build and evaluate fraud detection models

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Dataset
- Bank / Online Payment Transactions Dataset

## Methodology
- Exploratory Data Analysis (EDA)
- Feature engineering
- Train-test split
- Model training and evaluation

## Results & Insights
- Fraud cases are rare but high impact
- Certain transaction types show higher fraud probability
- ML models improve fraud detection accuracy

- `fraud_detection_bank_payments.ipynb`
